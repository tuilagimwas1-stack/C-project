

A concise C console program developed using Code::Blocks that prompts the user to input their username and displays a personalized greeting.

## Overview
- **Language:** C[cite: 1]
- **IDE:** Code::Blocks[cite: 1]
- **Functionality:** 
  1. Prompts the user with `Please enter username`[cite: 1].
  2. Reads a user-entered string using `scanf`[cite: 1].
  3. Outputs `hello ` followed by the entered name[cite: 1].
